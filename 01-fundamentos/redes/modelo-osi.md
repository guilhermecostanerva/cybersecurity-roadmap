# Modelo OSI

## 1. O que é?

O modelo OSI é um modelo conceitual que
organiza a comunicação de redes em sete
camadas.

## 2. As sete camadas

| Camada | Nome |
|---|---|
| 7 | Aplicação |
| 6 | Apresentação |
| 5 | Sessão |
| 4 | Transporte |
| 3 | Rede |
| 2 | Enlace |
| 1 | Física |

## 3. Principais conceitos

- Aplicação: interação com serviços de rede.
- Transporte: comunicação entre processos.
- Rede: endereçamento e roteamento.
- Enlace: comunicação dentro do enlace.
